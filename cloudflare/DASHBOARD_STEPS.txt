Cloudflare Workers 部署設定（getzenithmind.com / zenith-mind.com）
============================================

【重要】本專案為 Next.js 15 SSR，請使用 OpenNext 建置（非純靜態 export）。

【A】Pages → Settings → Builds
  Framework preset:  None（或 Next.js，但以下方命令為準）
  Build command:
    CF_PUBLIC_ONLY=1 SKIP_ENV_VALIDATION=true NODE_OPTIONS=--max-old-space-size=8192 npm run build:cf
    （平台已自動 npm ci，勿重複寫 npm ci；成功 log 應有 Skipping linting）
  Build output directory:
    .open-next
  Root directory:      /
  Node.js version:     22

【B】Pages → Settings → Environment variables（Production + Preview 建置都要）
  建置必填：
    CF_PUBLIC_ONLY=1
    SKIP_ENV_VALIDATION=true
    NODE_OPTIONS=--max-old-space-size=8192
    NEXT_PUBLIC_SITE_URL=https://www.getzenithmind.com

  執行階段必填（Production）：
    DATABASE_URL、DIRECT_URL、JWT_*、UPSTASH_*、SUPABASE_* 等（見下方）

  建置選填（有 DATABASE_URL 時可預生成文章靜態路徑，加快首屏）：
    DATABASE_URL=（與 Production 相同即可）

  執行階段必填（與 .env.example 一致，請填真實值）：
    NEXT_PUBLIC_SITE_URL=https://www.getzenithmind.com
    DATABASE_URL=
    DIRECT_URL=
    JWT_ACCESS_SECRET=
    JWT_REFRESH_SECRET=
    UPSTASH_REDIS_REST_URL=
    UPSTASH_REDIS_REST_TOKEN=
    TOTP_ENCRYPTION_KEY=
    GEMINI_API_KEY=
    GA4_CLIENT_EMAIL=
    GA4_PRIVATE_KEY=
    GA4_PROPERTY_ID=
    WEBHOOK_SECRET=
    SUPABASE_SERVICE_ROLE_KEY=
    NEXT_PUBLIC_SUPABASE_URL=
    NEXT_PUBLIC_SUPABASE_ANON_KEY=
    REDIRECT_LOOKUP_SECRET=

  公開變數已寫入 repo 的 wrangler.toml [vars]（隨 Git 部署）。
  敏感變數請用：npx wrangler secret put <NAME>（見 .dev.vars.example）

【C】Custom domains
  www.getzenithmind.com（主要，SEO canonical）
  getzenithmind.com（裸網域，Redirect Rule 301 → www）
  zenith-mind.vercel.app（後台；公開頁由 middleware 301 → www，避免重複內容）

【D】SSL/TLS
  Full (strict) + Always Use HTTPS ON

【E】裸網域 301 → www（Redirect Rules）
  Hostname equals getzenithmind.com
  → https://www.getzenithmind.com${http.request.uri.path}  (301)

【F】驗證
  部署 Success 後開啟：
  https://www.getzenithmind.com/logo.png
  https://www.getzenithmind.com/zh-TW

【G】本機 Windows 部署（Dashboard 503 時）
  勿用：CF_PUBLIC_ONLY=1 npm run build:cf 後 wrangler deploy
  （wrangler 會用 Unix 語法重跑 build，PowerShell 報「不是內部或外部命令」）

  請用：
    npm run deploy:cf

  或分兩步：
    npm run build:cf
    $env:CF_SKIP_BUILD="1"; npx wrangler deploy --no-bundle

  wrangler.toml [build].command 已改為 node scripts/cf-wrangler-build.mjs（跨平台）。
