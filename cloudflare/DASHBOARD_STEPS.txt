Cloudflare Pages 部署設定（getzenithmind.com）
============================================

【重要】本專案為 Next.js 15 SSR，請使用 OpenNext 建置（非純靜態 export）。

【A】Pages → Settings → Builds
  Framework preset:  None（或 Next.js，但以下方命令為準）
  Build command:
    SKIP_ENV_VALIDATION=true npm run build:cf
    （平台已自動 npm ci，勿重複寫 npm ci）
  Build output directory:
    .open-next
  Root directory:      /
  Node.js version:     22

【B】Pages → Settings → Environment variables（Production + Preview 建置都要）
  建置必填：
    SKIP_ENV_VALIDATION=true
    NEXT_PUBLIC_SITE_URL=https://www.getzenithmind.com

  執行階段必填（Production）：
    DATABASE_URL、DIRECT_URL、JWT_*、UPSTASH_*、SUPABASE_* 等（見下方）

  建置選填（有 DATABASE_URL 時可預生成文章靜態路徑，加快首屏）：
    DATABASE_URL=（與 Production 相同即可）

  執行階段必填（與 .env.example 一致，請填真實值）：
    NEXT_PUBLIC_SITE_URL=https://www.getzenithmind.com
    DATABASE_URL=
    DIRECT_URL=
    JWT_ACCESS_SECRET=
    JWT_REFRESH_SECRET=
    UPSTASH_REDIS_REST_URL=
    UPSTASH_REDIS_REST_TOKEN=
    TOTP_ENCRYPTION_KEY=
    GEMINI_API_KEY=
    GA4_CLIENT_EMAIL=
    GA4_PRIVATE_KEY=
    GA4_PROPERTY_ID=
    WEBHOOK_SECRET=
    SUPABASE_SERVICE_ROLE_KEY=
    NEXT_PUBLIC_SUPABASE_URL=
    NEXT_PUBLIC_SUPABASE_ANON_KEY=
    REDIRECT_LOOKUP_SECRET=

  Google Ads（選用，後台儀表板狀態用）：
    GOOGLE_ADS_CUSTOMER_ID=8702788584
    GOOGLE_ADS_LOGIN_CUSTOMER_ID=4708073999
    GOOGLE_ADS_DEVELOPER_TOKEN=（你的 Developer Token，勿用 DEVELOPER_TOKEN 當變數名）
    GOOGLE_ADS_CLIENT_ID=
    GOOGLE_ADS_CLIENT_SECRET=
    GOOGLE_ADS_REFRESH_TOKEN=

【C】Custom domains
  www.getzenithmind.com（主要）
  getzenithmind.com（裸網域，Redirect Rule 301 → www）

【D】SSL/TLS
  Full (strict) + Always Use HTTPS ON

【E】裸網域 301 → www（Redirect Rules）
  Hostname equals getzenithmind.com
  → https://www.getzenithmind.com${http.request.uri.path}  (301)

【F】驗證
